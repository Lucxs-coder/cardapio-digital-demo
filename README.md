# Sabor & Mesa — Cardápio Digital

Uma demonstração de portfólio de um cardápio digital responsivo. O projeto simula a descoberta de pratos, filtro por categoria, carrinho e confirmação de pedido — sem conectar a restaurante, hotel, WhatsApp ou banco de dados real.

## Demonstração

- Cardápio com dados totalmente fictícios
- Filtros por categoria
- Carrinho com alteração de quantidades e cálculo do total
- Confirmação de pedido simulada, sem envio de dados
- Interface responsiva, pensada para celular

## Tecnologias

- Next.js
- React
- TypeScript
- CSS responsivo

## Como executar

```bash
npm install
npm run dev
```

Depois, abra `http://localhost:3000` no navegador.

## Observações

Esta é uma versão demonstrativa para portfólio. As marcas, textos, pratos, preços e fluxos exibidos são fictícios.
